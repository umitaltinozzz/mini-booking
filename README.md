## Overview

Mini Randevu is a multi-tenant appointment and slot management experience built for small businesses — barbershops, salons, restaurants, and similar use cases. It ships a Next.js frontend with localized marketing pages, booking flows, and dashboard-style UI.

## Features

- **Internationalization** — Turkish and English via next-intl
- **Modern UI** — Tailwind CSS, Framer Motion, selective 3D visuals (React Three Fiber)
- **Multi-tenant UX** — tenant-scoped booking and admin screens
- **Responsive** — fully mobile-optimized

## Tech Stack

| Area | Choice |
|---|---|
| Framework | Next.js 16 (App Router), React 19 |
| Styling | Tailwind CSS 4 |
| i18n | next-intl |
| Forms | react-hook-form, Zod |
| Animation | Framer Motion |
| 3D | Three.js, @react-three/fiber |
